📋 TSA Client (RFC 3161)

Jednoduchý RFC 3161 timestamp klient postavený na OpenSSL. Komunikuje s TSA servermi na vytváranie časových pečiatok a ich lokálne overenie. Klient hashuje vstupný súbor (SHA-256), zostavuje TimeStampReq a uložieva prijatý token spolu s metadátami.

Verzia: v1.50
Východzí server: DigiCert (timestamp.digicert.com:80/)

🔨 Build

Potrebujete OpenSSL dev knižnice (libssl, libcrypto) pre GCC/MinGW.

make

Výstup: tsa_client_openssl.exe

📖 Použitie

Vytvorenie časovej pečiatky

tsa_client_openssl.exe [--server NAME] <súbor>

Príklady:

tsa_client_openssl.exe dokument.pdf
tsa_client_openssl.exe --server FreeTSA dokument.pdf

Overenie časovej pečiatky

tsa_client_openssl.exe -verify <súbor> [token.tsr] [trusted_cert]

Príklady:

tsa_client_openssl.exe -verify dokument.pdf
tsa_client_openssl.exe -verify dokument.pdf dokument.pdf.tsr
tsa_client_openssl.exe -verify dokument.pdf Certificates/FreeTSA.crt
Poznámka: Ak certifikát nie je poskytnutý, overuje sa iba podpis. Ak token nie je poskytnutý, automaticky sa použije <súbor>.tsr.

🖥️ Podporujeme TSA Servery

DigiCert - timestamp.digicert.com:80/ ✓ PASS
FreeTSA - freetsa.org:80/tsr ✓ PASS
Sectigo - timestamp.sectigo.com:80/ ✓ PASS
Certum - time.certum.pl:80/ ✓ PASS
GlobalSign - timestamp.globalsign.com:80/tsa/r6advanced1 ✓ PASS

🔐 Certifikáty

V adresári Certificates/ sú dostupné TSA certifikáty:

  • DigiCert.cer
  • FreeTSA.crt
  • Sectigo.crt
  • Certum.cer
  • GlobalSign.crt

📁 Vytvorené súbory

Pri vytváraní pečiatky sa vytvoria:

  • <súbor>.tsr - RFC 3161 časový token (binárny)
  • <súbor>.metadata.txt - metadáta (Gen čas, serial, policy, hash)

📊 Podporujeme formáty

  • Hash: SHA-256
  • Standard: RFC 3161
  • Certifikáty: X.509 (PEM/DER)
  • HTTP: POST, chunked encoding (RFC 7230)

🔧 Implementačné detaily

  • Hashing: EVP_sha256() (čunkové čítanie)
  • RFC 3161: TS_REQ, TS_RESP, TS_TST_INFO
  • PKCS7: PKCS7_verify() s PKCS7_NOVERIFY flagom
  • HTTP: BIO_new_connect(), manuálne parsovanie headers
  • Chunked: RFC 7230 dekódovanie
